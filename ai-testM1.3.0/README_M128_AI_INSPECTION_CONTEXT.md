# 똑띠체크 M1.2.8 — 저장된 점검자료 자동참조

- 질문만 입력해도 현재 열려 있는 시험 점검 문서(demo/current)의 현장정보, 설비별 측정값표, 판정·사유·조치사항을 AI에 전송합니다.
- 지정된 설비번호 우선, 지정이 없으면 현재 선택 설비 우선. 나머지 설비도 텍스트 컨텍스트에 포함합니다(용량 제한 내).
- 사진은 별도 첨부 없이 원본 저장 데이터에서 전송용으로만 축소(최대 5장, 긴 변 640px)하여 보냅니다. 한 번의 질문에서 전체 사진을 분석하는 기능이 아닙니다.
- 데이터는 읽기 전용이며 Supabase/IndexedDB 저장 구조·SQL·권한·브랜드 이미지 변경 없음.

## 필수 배포 2곳
1. GitHub Pages: ZIP의 index.html, checklist.html, assets 폴더 등을 기존 ai-test 경로에 배포.
2. **별도 필수**: AI TEST Supabase 프로젝트의 Edge Functions > ttoktti-ai에서 `supabase/functions/ttoktti-ai/index.ts`를 최신 코드로 교체·배포. GitHub 파일만 교체하면 서버의 4KB 제한 때문에 413 오류가 발생할 수 있습니다.
3. 로그인 후 CH-1을 선택하거나 질문에 CH-1을 포함하고, 사진·판정·측정값을 입력한 상태에서 질문. AI 결과에 실제 수신한 자료가 반영되는지 확인.
4. 질문 전 현재 작성 자료를 JSON 백업해 두세요.

## 보안 및 제한
- 인증된 시험계정만 AI 호출 가능, 기존 승인/쿼터 로직 유지. 프로젝트 공개키 유지, 서비스 키는 브라우저에 넣지 않음.
- 등록된 사진의 AI 분석을 위해 이미지가 AI 서비스로 전송됩니다. 점검사진 안의 개인정보/민감정보를 확인한 후 사용하세요.
- 한 번에 사진 최대 5장, 응답당 서버 요청 1.7MB 제한. 텍스트도 용량을 초과하면 잘릴 수 있습니다.
- 서버 배포 및 실제 로그인/AI 이미지 분석은 현 환경에서 실계정으로 검증하지 못했습니다.
