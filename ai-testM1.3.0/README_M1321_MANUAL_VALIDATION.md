## 꼭 확인할 항목
- 부록의 26개 공식 서식과 앱의 27개 설비 선택 유형은 구분해야 합니다.
- 신재생에너지 지열·태양열은 공식 신재생에너지 시스템 1종 서식으로 공통 처리되며, 연료전지는 별도 서식입니다.
- 매뉴얼 원문과 현재 앱의 항목명 또는 항목 수가 다른 것은 임의 삭제하지 않고 추가 검토 페이지로 분리했습니다.
- 복잡한 수치표·수식·병합셀은 원문을 평문 형태로 가져왔으므로 별도 육안 교정 전에는 완전 동일하다고 볼 수 없습니다.
- 냉동기 출력은 기존 합의된 서식 그대로 유지합니다.
- 기존 Supabase·IndexedDB의 데이터 구조와 사진 저장 방식은 변경하지 않았습니다.
