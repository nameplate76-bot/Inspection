# 똑띠체크 M1.3.3 — 똑띠i 질문 목록 복귀

- 기존 M1.3.2 전체 파일 기반.
- 질문 선택 또는 직접 입력 후 상단에 ‘← 질문 목록 보기’ 표시.
- 누르면 대화창을 닫지 않고 초기 질문 목록으로 돌아갑니다.
- AI 답변 대기 중에도 목록으로 복귀 가능하며 이전 응답이 새 목록에 나타나지 않도록 세션을 분리합니다.
- 기존 점검자료, 사진, 측정값, 인증, 동기화, Edge Function, SQL은 수정하지 않았습니다.
- GitHub Pages 배포 시 기존 파일 백업 후 ZIP의 웹 파일을 동일 경로에 업로드하세요.
- Supabase SQL 실행 및 Edge Function 재배포는 필요하지 않습니다.
- 검증: JavaScript 구문 검사 통과. 브라우저 실제 운영 로그인/클라우드 동작은 별도 확인이 필요합니다.
