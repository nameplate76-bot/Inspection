# M1.3.20 사진 보관함 사용성 수정

- 사진 보관함 열기/닫기 버튼을 실제 접기·펼치기 동작으로 수정.
- 사진마다 반복되던 내보내기 버튼을 제거. 사진 여러 장을 체크해 일괄 공유(지원되는 기기의 최대 10장)하거나 ZIP으로 내보내기.
- iPhone 사진 앱 자동 저장은 일반 웹페이지에서 불가능. 공유 시트에서 사용자가 이미지 저장을 선택해야 함. ZIP은 파일 앱으로 저장.
- 현재 첨부 사진과 삭제/교체된 과거 사진을 분리. 기본 목록에서는 삭제한 사진이 나타나지 않음.
- 삭제/교체된 사진 원본은 복구 보관함에 유지하고, 사용자 확인 후 선택 영구 삭제 가능. 원격 사진·점검표 원본은 복구 보관함 조작으로 삭제하지 않음.
- 기존 M1.3.19 IndexedDB 스키마와 동일하며 데이터 삭제/마이그레이션 없음.
- GitHub: Inspection/ai-testM1.3.0, 기존 supabase-config.js 수정 불필요.
- 실기기에서 다중 사진 공유·Safari 파일 다운로드·사진 삭제 후 목록 상태를 확인해야 함.
