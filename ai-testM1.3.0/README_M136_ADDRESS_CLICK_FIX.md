# 똑띠체크 M1.3.6 — 주소 검색 버튼 이벤트 복구

## 확인된 근본 원인
`assets/legacy-checklist-engine.js`의 원래 `bind()` 함수에는 `data-address-search` 클릭 이벤트가 있었으나, 아래에서 `bind=bindV2`로 덮어쓰면서 주소 버튼 이벤트 연결이 소실되었습니다. 이에 버튼을 클릭해도 아무 반응이 없었습니다.

## 변경 사항
- 실제 사용되는 `bindV2()`에 주소 검색 이벤트 연결 추가
- 브라우저 기본 동작 중지 후 화면 내부 우편번호 검색창 실행
- 오류 발생 시 안내, 개발자 콘솔 로깅
- 버전 M1.3.6로 동기화: 메인/점검표, 공통 버전 설정, 리소스 캐시 식별자
- 기존 점검자료/사진/설비/AI 기능, 운영 DB, 인증 및 권한 처리 변경 없음

## GitHub 업로드
기존 `performance/` 디렉터리에 압축 파일의 폴더 구조를 유지해 덮어쓰기. 설정파일은 기존 운영 설정과 비교 후 보호. 최소 업로드 파일: `assets/legacy-checklist-engine.js`, `assets/app-version.js`, `assets/permission-gate.js`, `index.html`, `checklist.html`.

## 확인 절차
1. GitHub Pages 배포 후 Ctrl+Shift+R 강력 새로고침.
2. 점검표 화면에 M1.3.6 표시 확인.
3. 주소 검색 버튼 클릭하여 화면 내부 검색창 열리는지 확인.
4. 건물명/도로명 검색, 주소 선택으로 주소 입력란에 자동 반영.
5. 새로고침 후 이전 주소값 유지 확인.

참고: 다음(카카오) 우편번호 외부 스크립트 연결은 인터넷/브라우저 정책에 따라 실패할 수 있습니다. 현장 브라우저에서의 최종 기능 검증은 사용자가 배포 후 수행해야 합니다.
