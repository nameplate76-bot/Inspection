# M1.3.8 — 기본정보·현장사진 돌아가기 버튼 가독성 수정

- 점검항목 작성 화면의 `← 기본정보·현장사진` 버튼을 남색 배경/흰색 굵은 글씨/두꺼운 테두리/그림자로 강조했습니다.
- PC에서는 측정값 버튼과 나란히 표시되며, 모바일(700px 이하)에서는 가로 전체 너비로 각각 표시됩니다.
- 기존 버튼 클릭 동작과 저장·동기화·점검자료 코드는 변경하지 않았습니다.
- 메인/점검표 표시 버전을 M1.3.8로 변경하고 캐시 무효화 쿼리를 갱신했습니다.
- 업로드: ZIP 압축 해제 후 기존 `performance` 경로에 같은 폴더 구조로 업로드. 기존 별도 환경설정 파일은 덮어쓰지 마세요.
- 확인: 점검항목 화면의 버튼 가독성, 클릭 시 기본정보·현장사진 화면 복귀, 모바일 표시.
- 실제 운영 서버/휴대폰 브라우저 테스트는 배포 후 확인해야 합니다.
