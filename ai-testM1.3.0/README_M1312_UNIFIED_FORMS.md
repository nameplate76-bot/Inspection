# 똑띠체크 M1.3.12 — 냉동기 기준 26종 점검표 양식 통일

## 적용 범위
- 냉동기 양식 자체는 변경하지 않음
- 냉각탑부터 방음방진내진까지 26종 설비(템플릿 총 27종)의 **PDF 출력 양식**을 냉동기 V85 스타일로 통일
- 점검 요약표 / 설비번호·점검일·점검자 / 점검방법과 기준 표 / 사진 및 적합·미흡 사유 / 측정값·확인내용 / 후속 측정값표 순서 유지
- 원본 템플릿 기준 문장, 판정, 측정값, 사진 및 동기화/계정 로직 불변
- 긴 점검기준은 기준 페이지와 사진 페이지로 분리
- 기존 Excel 출력은 이미 공통 10pt 맑은 고딕·청색 표 헤더·점검방법/기준 구분 형태로 구현되어 있으므로 이번에는 변경하지 않음

## 확인 방법
1. 기존 점검내용을 JSON 백업
2. 냉동기+냉각탑+보일러+방음방진내진 예시 설비를 각각 만든 후 PDF 미리보기
3. 모든 설비별 요약·세부 페이지의 글꼴, 크기, 파랑 표 헤더와 표 열 너비 확인
4. 긴 기준 문구나 사진이 잘리지 않는지 A4 인쇄 미리보기에서 확인
5. 냉동기 PDF는 M1.3.11과 동일한지 비교

**주의**: 브라우저 실제 A4 렌더링·PC/모바일 동시 테스트 미수행. 서버/DB/Storage에는 접근하거나 변경하지 않았음.
