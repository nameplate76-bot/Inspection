# 똑띠체크 M1.3.0 테스트용 권한 강화 패키지

## 변경사항
- 조회 / 작성·수정 / 삭제 / PDF·Excel·JSON 출력 / PC·모바일 동기화 / 똑띠i의 6개 권한.
- 똑띠i 서버 `ttoktti-ai`에서 JWT로 사용자를 확인한 뒤 `tt_users.active` 및 `ai` 권한을 검사. 사용량 조회(`status`) 역시 허가된 사용자만 가능.
- 사용자 관리 `ttoktti-admin`에서는 서비스 역할 서버만 계정 생성·수정 가능. 일반 사용자는 API 직접 호출해도 관리자 권한 없음.
- 동기화 SQL은 owner_id 기준 RLS SELECT/INSERT/UPDATE/DELETE, 비활성 계정 차단, 수정권한 없는 사용자 쓰기 차단.
- 점검표 JS를 로그인 및 조회권한 확인 후에만 로드하고, PC의 브라우저 IndexedDB 저장 공간을 계정 UUID별로 분리.
- 체크리스트 화면 버튼과 입력도 각 권한에 맞게 차단. 삭제 기능은 삭제+수정 권한 두 가지 모두 필요.
- 기존 고정 로고·캐릭터 원본 파일의 바이트는 변경하지 않음.

## 중요한 제한과 미완료 검증
1. GitHub Pages의 클라이언트 자바스크립트만으로는 보안이 성립하지 않습니다. 서버 RLS와 Edge Functions 설치가 필수입니다.
2. `document`가 하나의 JSONB 덩어리인 기존 시험 구조이므로 장비 삭제 및 설비 현장 사진 삭제는 서버 트리거가 감지하지만, **항목 내부 사유/측정값/사진 삭제와 단순 수정의 차이를 서버에서 완벽하게 판정하지 못합니다**. 기능별 삭제 권한을 완전한 서버 보안으로 만들려면 점검항목을 별도 DB 행으로 정규화하거나 삭제 전용 서버 API가 필요합니다. 현재 ZIP은 운영 수준의 완성본이 아닙니다.
3. 기존 M1.2.8 및 M1.2.9의 브라우저 로컬 시험자료는 계정별 새 저장소로 **자동 이동하지 않습니다**. 백업 후 기존 자료 이관을 계획해야 합니다.
4. 인증, 로그인, 동기화, AI 서버 호출, 실제 SQL 실행을 여기서 외부 프로젝트에 대해 검증하지 않았습니다. Deno 배포/SQL 실행 및 브라우저 E2E는 테스트 환경에서 별도 확인해야 합니다.
5. 현재 동기화 문서는 계정당 `demo/current` 한 개입니다. 여러 현장·협업 권한이나 운영보고서 접근 권한까지 통합한 구조는 아닙니다.
6. 사용량은 기존 AI 요금제 DB 및 RPC 기준입니다. 기존 AI 승인 테이블은 M1.3.0 AI 서버 권한 판단에 사용하지 않습니다. RPC 자체를 외부에서 직접 호출할 수 없도록 GRANT 및 실행권한 검토가 필요합니다.

## 설치 순서 (운영 데이터 변경 금지)
1. 기존 GitHub, Supabase DB와 Storage를 각각 별도 백업합니다.
2. AI **테스트** Supabase 프로젝트에서 기존 M1.2.9 필요 테이블을 먼저 확인합니다.
3. `TTOKTTI_M130_PERMISSIONS_TEST_ONLY.sql` 내용을 검토하고 **테스트 프로젝트에서만** 실행합니다.
4. `supabase/functions/ttoktti-ai/index.ts`, `ttoktti-admin/index.ts`를 테스트 프로젝트에 배포합니다. 각 Edge Function의 JWT 설정, 허용 Origin, 환경변수를 확인합니다.
5. 테스트용 GitHub Pages 별도 경로에 배포해 아래 시나리오를 검증합니다. 운영 GitHub에 곧바로 덮어쓰지 마세요.

## 필수 시험 시나리오
- 비로그인, 비활성 사용자, 조회 미허용 사용자: 점검표 접근 및 동기화 요청 거부
- 조회만 허용: 읽기 가능, 저장/삭제/출력/AI 요청 차단
- 조회+편집: 저장 가능, 삭제 및 출력 차단, 서버에서 설비 삭제 시도 거부
- 조회+편집+삭제: 설비 삭제 가능, 타 계정 owner_id 업데이트/삭제 거부
- 조회+출력: PDF/Excel/JSON 버튼 사용 가능, 수정 불가
- 조회+동기화: 클라우드 읽기만 가능, 편집 없으면 업로드 차단
- AI 권한 꺼짐: AI UI 및 직접 Edge Function 요청 모두 403
- AI 권한 켜짐: status 조회 및 질문 사용량 집계 확인
- 세션 만료/관리자 사용자 중지/권한 회수 후 새 요청 거부
- 다른 사용자 계정으로 로그인: 이전 사용자의 로컬 점검자료가 표시되지 않음
- PC/모바일 동일 계정 로그인, 최초 업로드 및 충돌 처리 정상 동작
- 기존 로고/캐릭터 자산과 점검표 27종 기능 회귀 테스트
