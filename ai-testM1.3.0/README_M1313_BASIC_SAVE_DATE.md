# 똑띠체크 M1.3.13 — 설비 기본정보 저장 및 점검일 숫자 변환

- 설비 기본정보 입력·수정 팝업에 `저장하기` 버튼 및 저장 상태 표시 추가. 저장 완료 후 기존 점검표 화면으로 돌아갑니다.
- 기존 입력 중 자동 저장은 유지하되, 사용자가 저장 완료를 직접 확인할 수 있습니다.
- 점검일에 `20261120` 입력 시 `2026-11-20`으로 자동 변환. `2026-11-20`도 지원.
- 20260230 등 유효하지 않은 날짜는 오류 표시하고 저장 완료/닫기를 차단합니다.
- 날짜 선택기를 이용한 입력도 동일한 ISO 형식으로 저장됩니다.
- 기존 설비 정보, 사진, 측정값 및 클라우드 동기화 코드는 변경하지 않습니다.
- JavaScript 문법 검사를 통과해야 하지만 실제 브라우저/클라우드 동작은 배포 후 검증이 필요합니다.
