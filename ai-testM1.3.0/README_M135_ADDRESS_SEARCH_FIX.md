# 똑띠체크 M1.3.5 — 주소 검색 기능 개선

- 기존 M1.3.4 주소 검색은 검색 스크립트 로딩 이후 별도 팝업을 열어 브라우저 환경에 따라 차단될 수 있었습니다.
- M1.3.5는 주소 검색 버튼 클릭 시 앱 화면 내부에 검색창을 먼저 띄우고, 카카오(다음) 우편번호 API를 임베드하여 사용합니다. 별도의 팝업 허용이 필요하지 않습니다.
- 주소를 선택하면 기존 현장 기본정보 `주소` 필드에 입력하고 기존 `input` 저장 이벤트를 호출합니다.
- 검색 서비스 로딩 실패 또는 연결 시간 초과 시 오류 메시지와 다시 시도 버튼을 제공합니다. 서비스가 차단된 환경에서는 기존 직접 입력을 사용할 수 있습니다.
- `assets/app-version.js`의 버전을 M1.3.5로 변경했고 index.html 및 checklist.html의 캐시 버전과 기본 표시를 맞췄습니다.
- Supabase 스키마, API 키, 사용 권한, 사진, 측정값, 보고서, AI 엔진은 변경하지 않았습니다.

## 배포
GitHub Inspection 저장소의 `performance/` 폴더에 압축 해제한 파일들을 업로드하십시오. 운영 설정 파일 `../supabase-config.js`를 덮어쓰거나 삭제하지 마십시오. 필수 변경 파일: `index.html`, `checklist.html`, `assets/app-version.js`, `assets/legacy-checklist-engine.js`, `assets/permission-gate.js`.

## 확인
1. 메인/점검표 화면 버전 M1.3.5 확인
2. 현장 기본정보의 주소 검색 버튼 클릭 → 화면 내부 주소 검색창 열림 확인
3. 도로명 또는 건물명 입력 → 결과 선택 → 주소 자동 반영 확인
4. 새로고침 후 주소 저장 여부 확인
5. 다른 점검 기능 및 기존 사진/측정값 유지 확인

참고: 주소 검색 서비스는 외부 CDN에 의존하므로 인터넷 또는 외부 스크립트 차단 환경에서 제한될 수 있습니다.
