# 똑띠체크 M1.3.4 수정사항

- 현장 기본정보의 주소 항목에 **주소 검색** 버튼 추가. 카카오(다음) 우편번호 서비스로 도로명/지번/건물명을 검색하고 선택한 주소를 기존 `d.info["주소"]`에 저장합니다. 검색이 불가능하면 기존 직접 입력을 사용합니다. 주소 검색은 인터넷 연결 및 외부 서비스 접근이 필요합니다.
- 버전 단일 설정 파일: `assets/app-version.js`. 화면의 독립 모듈 버전과 동적 점검 엔진 캐시 버전이 이를 참조합니다. 다음 버전은 해당 파일의 `TTOKTTI_APP_VERSION` 값을 변경하고 HTML 캐시 쿼리와 배포 파일명도 업데이트하세요.
- 기존 사진, 측정값, 사유, 권한, Supabase SQL 및 저장 구조 변경 없음.
- GitHub Pages 배포: ZIP 안의 파일과 폴더를 기존 `Inspection/performance/` 경로에 같은 구조로 업로드합니다. `supabase-config.js`는 이 ZIP에 포함되지 않으며 기존 설정을 보존합니다.
- 점검: 주소 검색 → 선택 → 입력 칸 반영 → 새로고침 후 주소 유지; 화면 M1.3.4 표시; 기존 점검 사진/측정값 확인.
