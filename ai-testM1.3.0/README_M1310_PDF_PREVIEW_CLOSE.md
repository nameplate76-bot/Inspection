# 똑띠체크 M1.3.10 — PDF 미리보기 닫기 버튼

- `점검표 PDF 미리보기` 클릭 시 새 창 상단에 `← 닫기 · 점검표로 돌아가기` 버튼 추가.
- 닫기 클릭 시 원래 점검표 창에 포커스를 준 후 `window.close()`로 미리보기 창을 종료.
- 일부 브라우저에서 창 닫기를 제한하면 원래 탭으로 돌아가거나 탭을 닫도록 안내.
- 모바일에서 누르기 쉬운 버튼 크기(최소 높이 46px), 명확한 대비, 키보드 포커스 스타일 추가.
- 인쇄 시 버튼 및 안내가 PDF에 인쇄되지 않도록 기존 `@media print` 적용 유지.
- 메인 화면/점검표 화면 버전 `M1.3.10`으로 변경, 서비스 워커 캐시명 갱신.
- 운영 DB/사진/측정값/로그인 권한 및 기존 데이터 구조는 변경하지 않음.

## 배포
GitHub `Inspection/performance` 아래 동일 경로로 덮어쓰기. 기존 오프라인 캐시를 갱신하기 위해 브라우저를 새로고침하세요. `supabase-config.js` 등의 실제 운영 설정을 변경하지 마세요.

## 기능 확인
1. 점검표에서 `점검표 PDF 미리보기` 선택.
2. 상단에 `PDF로 저장 / 인쇄`와 `← 닫기 · 점검표로 돌아가기` 두 버튼이 나타나는지 확인.
3. 닫기 버튼 클릭 시 기존 점검표 창으로 복귀되는지 확인.
4. PDF 인쇄 시 새 버튼이 인쇄물에 포함되지 않는지 확인.
5. PC Chrome과 모바일 Safari에서 확인.

참고: 자동화된 브라우저에서 실제 클릭/인쇄 동작을 확인한 것은 아닙니다.
