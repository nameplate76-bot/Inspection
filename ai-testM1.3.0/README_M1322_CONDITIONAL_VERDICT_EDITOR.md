# M1.3.22 — 점검항목 판정별 조건부 입력 화면

기준: M1.3.21. 기존 사진, 사유, 설계·측정값, 조치사항, 계정·권한·오프라인·동기화 데이터와 PDF/Excel 출력 구조는 변경하지 않았습니다.

## 입력 화면
- 점검항목을 열면 판정과 현황 사진만 기본 노출. 원본 점검방법·기준은 기존처럼 접힌 상태.
- 적합/미사용/해당없음: 현황 + 적합 사진·사유.
- 미흡/조치필요: 현황 + 미흡사항 사진·사유.
- 미작성/측정불가: 현황 사진만 기본 노출.
- `다른 판정 사진·사유 보기`: 숨겨진 적합/미흡 입력란 모두 펼치기. 누르면 다시 접기. 해당 설비·항목 내 이동 시 열림 상태 유지.
- 설계·측정값(별도 화면 버튼 유지) 및 조치사항/확인내용은 `측정값·조치사항 추가 입력`을 열어 수정 가능.
- 냉동기 ⑤번 진공펌프 추가 사진·사유에도 동일 표시 규칙 적용.

## 데이터·출력
- DOM 영역만 숨기며 photos[0..5], reason1/reason2, vacuumReason1/vacuumReason2 등 어떤 값도 삭제/초기화하지 않습니다.
- PDF·Excel 보고서 출력 로직은 변경하지 않았으므로 적합과 미흡사항이 기존처럼 동시에 출력됩니다.
- `미사용`은 새 판정으로 보존하며 제출용 판정 기호는 기존 `해당없음`과 동일한 `/`로 표시됩니다. 이 표기 방식은 제출처 요구사항에 맞춰 확인하세요.
