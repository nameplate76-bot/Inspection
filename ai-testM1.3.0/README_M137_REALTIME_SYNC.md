# 똑띠체크 M1.3.7 PC·모바일 자동 동기화 보완

- 기존 M1.3.6의 `assets/cloud-sync.js`를 보완했습니다.
- 동일한 로그인 계정(owner_id)의 `demo/current` 시험 점검표만 공유합니다. **서로 다른 계정끼리 공유하지 않습니다.**
- 로컬 저장 완료 후 약 0.9초의 디바운스로 클라우드 저장을 시도합니다. Supabase Realtime 이벤트를 수신하며 5초 간격 폴링을 대체 경로로 사용합니다. 네트워크와 서버 상태에 따라 실제 반영시간은 달라집니다.
- 저장된 문서의 해시 및 클라우드 revision을 기기별로 별도 보관하여, 이전에 동기화된 기기가 재접속했을 때 최신 클라우드 자료를 자동 불러옵니다.
- 로컬 문서가 클라우드와 다르고 마지막 동기화가 확인되지 않으면 자동 덮어쓰지 않습니다. JSON 백업 후 사용자가 수동으로 선택합니다.
- 사진은 기존 데이터 URL(base64)로 JSON 전체에 포함되어 전송됩니다. 24MB 이상의 데이터는 안전을 위해 차단되며, 규모가 커지면 별도 Supabase Storage 방식으로 설계를 변경해야 합니다.
- 사용자가 `클라우드 자료 없음`을 보면 **최초 1회만** `이 기기 자료 클라우드에 올리기` 버튼을 눌러야 합니다. 기존 기기 자료를 덮어쓰지 않도록 JSON 백업 후 진행하세요.
- `supabase_realtime` publication에 `public.pjt_performance_test_docs_v1`이 포함되어 있는지 확인하세요. 포함되지 않으면 5초 폴링 방식으로 반영될 수 있습니다.
- 기존 Supabase 테이블, RLS, Storage, 인증/권한, 운영 데이터는 수정하지 않았습니다. 새 SQL 실행은 필수 아님.
- **주의**: 이 버전은 서로 다른 계정 간 현장 공유나 다중 동시편집의 필드 단위 병합을 구현하지 않습니다. 한 문서를 동시에 편집하면 revision 충돌이 발생하고 자동 덮어쓰기를 중지합니다.
- 테스트: 같은 계정으로 PC/휴대폰 로그인 → PC에서 클라우드 최초 업로드 → 모바일에서 클라우드 불러오기 또는 로컬 자료가 비어 있으면 자동 수신 → 모바일 사진+사유 입력 → 상태 `클라우드 저장 완료` → PC 변화 확인. 반대로 테스트.
