PJT 진행현황 모바일 웹앱 v5

[대시보드]
- 전체 진행 중 = 점검대상 + 점검 진행 중 + 점검 완료
- 점검대상 = 진행 중 중 현장점검 종료일 없음
- 점검 진행 중 = 진행 중 중 현장점검 계획일 있음 + 현장점검 종료일 없음
- 점검 완료 = 점검대상 - 점검 진행 중
- 보고서 미작성 = 진행 중 중 보고서 작성 완료일 없음
- 보고서 완료 = 전체 진행 중 - 보고서 미작성

[추천 기본 검색 표시 항목]
- 현장명
- 지역
- 문서작성 > 담당
- 문서작성 > 제본 입고
- 현장점검원
- 현장점검 종료
- 영업 담당
- 관리주체 담당자
- 관리주체 연락처

[엑셀 가져오기]
- 상단 '엑셀 가져오기' 버튼 사용
- .xlsx / .xls / .csv 지원
- '진행중' 시트가 있으면 우선 읽고, 없으면 첫 번째 시트를 읽습니다.
- 현장명이 있는 행만 가져옵니다.
- 확인: 기존 데이터를 모두 교체
- 취소: 기존 데이터에 추가

[엑셀 내보내기]
- 현재 웹앱에 보이는 전체 데이터(원본 + 수정 + 신규 + 가져온 데이터)를 62개 열로 저장합니다.
- '진행중' 시트로 생성합니다.

※ SheetJS CDN을 사용하므로 GitHub Pages 또는 인터넷 연결 상태에서 엑셀 가져오기/내보내기가 정상 작동합니다.
