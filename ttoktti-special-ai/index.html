운영 시스템과 분리된 테스트
이 페이지는 OpenAI 실시간 응답이나 Supabase에 연결되지 않습니다. 사용자가 선택한 JSON 데이터는 브라우저 안에서만 분석하며 자동 업로드·저장하지 않습니다. 결과는 법정 성능점검 판정이 아닌 검토용 초안입니다.

① 분석 자료 선택

기존 똑띠체크의 읽기 전용 TTOKTTI_READ_INSPECTION_CONTEXT 반환 구조 또는 data.equipment JSON을 지원합니다. 원본 DB의 직접 연결은 지원하지 않습니다.

② 기준 적용 설정

가상 기준: 증발기(냉수) / 출구온도 / 6~9℃. 체크하지 않으면 승인된 기준이 없어 판정 보류합니다.
실제 기준은 적용 법령·매뉴얼·설비 운전 조건을 전문가가 검증한 뒤 입력해야 합니다. 기준이 불충분하거나 중복되면 판정을 보류합니다.

분석 구조 안내

이 엔진은 기존 engine/*.mjs로 동작합니다. 사진 파일 및 이미지 URL은 읽거나 외부로 전송하지 않습니다. 측정값이 없거나 승인 기준이 없으면 판정을 보류합니다.
