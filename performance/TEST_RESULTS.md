## 검증 환경과 한계

- Chromium의 실행 환경 정책 때문에 `http://localhost`나 `file://`로 직접 이동하는 통합 시험은 차단되었습니다.
- 따라서 브라우저 UI 동작 테스트는 **Chromium에서 콘텐츠를 주입하고 IndexedDB/localStorage를 흉내 낸 격리 환경**에서 실행했습니다. 이 방식으로 사진, 판정, 측정값, PDF 및 Excel 동작을 확인했으나 **실제 GitHub Pages에서의 저장 지속성 및 새로고침/브라우저 재시작 테스트는 완료되지 않았습니다.**
- 운영 Supabase 프로젝트 또는 실사용자 계정에 연결하지 않았으며 SQL/Storage 변경도 수행하지 않았습니다.
- 모바일 Safari의 카메라 촬영, 실물 사진 대량 첨부, 사용자 권한 및 회사 서버 동기화는 단계 2에서 검증해야 합니다.
- 생성된 PDF는 V86 기준의 시험 출력물이며 원본 148페이지의 정밀한 글꼴·표·페이지 일치 검증은 이 단계 목표가 아닙니다.

## 단계 2 권장 후속

1. 실제 GitHub Pages에 배포하여 별도 브라우저 IndexedDB 저장·재조회 확인.
2. 설비별 PDF/Excel 인쇄 구조를 독립 `templates/` 및 `export/`로 분리.
3. 운영 포털이 전달할 `siteId`, `equipmentId`, `userRole` 등의 통합 인터페이스 정의.
4. 운영 데이터의 읽기 전용 미리보기 및 복사본을 이용한 데이터 이관 검증 후 통합.
