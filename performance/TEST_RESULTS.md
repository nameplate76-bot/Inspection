# 성능점검표 독립 모듈 M1.0.2 — 검증 기록

## 수정 범위

1. 현황사진 사진칸과 아래 빈칸의 세로 병합 (적합/미흡 사유칸은 유지)
2. 점검기준만 있는 경우 「점검기준」만 표시, 명확한 방법이 있는 경우 「점검방법」·「점검기준」 행 분리
3. 세부 점검표 PDF/Excel 출력 시 「판정」, 「조치사항」 행을 제거 (입력 데이터는 유지)
4. 현황/적합/미흡 사진의 비율에 관계없는 채움, 입력 화면 및 인쇄 PDF는 1px 여백
5. 운영 V86/운영 Supabase는 수정하지 않음. 테스트 IndexedDB 명칭과 저장 키 동일.

## 시험 결과

- Chromium 기반 독립 환경에서 M1.0.2 화면 버전 노출: 통과
- 냉동기 항목① 점검기준 3개가 세 개 행으로 표시됨: 통과
- 냉동기 항목②, ⑥ 점검방법/점검기준 분리: 통과
- 냉동기 현황사진 표 rowspan=2, 두 사유칸 유지: 통과
- 사진 입력 UI 이미지 inset 1px / object-fit: fill: 통과
- 냉동기 PDF 인쇄 이미지 object-fit: fill: 통과
- 세부 점검표 판정/조치사항 출력 제외, 입력 데이터 유지: 통과
- 냉각탑 다른 설비 출력에서 같은 공통 규칙 적용: 통과
- 냉동기 시험 PDF 15페이지 생성: 통과 (원본과의 전면 동일성 인증 아님)
- 냉각탑 시험 PDF 7페이지 생성: 통과
- 냉동기 편집형 XLSX 17시트 + 사진 생성 및 ZIP 검사: 통과
- XLSX 별도 스프레드시트 라이브러리에서 열기: 통과
- JavaScript 구문 검사 및 ZIP 무결성 검사: 통과

## 확인 제한

- 운영 Supabase 및 사용자 현장 데이터에서의 실제 동작은 시험하지 않았음 (의도적 격리).
- 27종 템플릿은 V86에서 변경하지 않았지만 모든 장비의 완전한 PDF·Excel 시각 대조는 아직 수행하지 않았음.
- 원본 PDF의 모든 법령 표 및 폰트 일치 여부는 별도 정밀 작업 필요.
- Excel의 그림 앵커는 실제 Excel 버전, 인쇄 설정 및 확대율에 따라 1px 근접 배치가 조금 달라질 수 있음.
