# M1.0.3 PC·모바일 동기화 검증 표

| 번호 | 테스트 | 예상 결과 |
| --- | --- | --- |
| 1 | 미로그인으로 URL 접속 | 로컬 점검표 입력 가능, 서버 자료 접근 없음 |
| 2 | 업무포털에서 승인된 계정으로 로그인 | 승인 계정 정보 표시 |
| 3 | PC 기존 자료 JSON 백업 후 업로드 | 시험용 클라우드 문서 등록, 버전 표시 |
| 4 | 모바일에서 동일 계정 로그인 | PC의 설비번호와 사진·사유·측정값 표시 |
| 5 | 모바일에서 사유 수정 후 잠시 유지 | PC 화면이 변경사항 반영 |
| 6 | PC에서 사진 첨부 | 모바일에서도 사진 표시 |
| 7 | PC와 모바일에서 동시에 다른 내용 수정 | 마지막 저장내용 자동 덮어쓰기 차단, 충돌 표시 |
| 8 | 인터넷 차단 후 입력 | 로컬 저장 유지, 클라우드 오류 상태 표시 |
| 9 | 인터넷 복원 | 충돌 없으면 클라우드 재동기화 |
| 10 | 승인되지 않은 계정 사용 | 클라우드 조회·저장 불가 |
| 11 | 다른 사용자 계정으로 접속 | 이전 계정 문서 조회 불가 |
| 12 | 기존 V86 업무포털 사용 | 모든 기존 기능 영향 없음 |

본 ZIP은 소스·정적 구문 및 DB 정책 확인 수준이며, 실제 2대 단말의 동일 사용자 로그인 검증은 사용자의 실기기에서 확인해야 합니다.
