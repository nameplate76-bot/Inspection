# M1.1.3 — 똑띠i 도움말 닫기 시 최초 화면 초기화

- 기준 버전: M1.1.2 전체 ZIP.
- 도움말 닫기(X), 캐릭터 버튼 닫기, Esc 키 닫기 모두 대화 기록 및 질문 입력란을 초기화합니다.
- 다시 열면 처음 인사말과 추천 질문 목록이 매번 표시됩니다.
- 데이터 삭제 없음: 점검표 내용, 사진, 측정값, 보고서 생성, Supabase 동기화, SQL 및 기존 저장 동작은 수정하지 않았습니다.
- 새로운 생성형 AI 기능은 이 버전에 아직 연결되지 않았습니다. 인증된 백엔드(예: Supabase Edge Function)에서 OpenAI Responses API를 호출하도록 별도 구성해야 합니다. API 키를 GitHub Pages 또는 브라우저 코드에 저장하지 마세요.
- 첨부된 공식 캐릭터 및 똑띠체크 상표 이미지 파일은 이전 버전과 바이트 단위 동일하게 유지했습니다.

# M1.1.2 — 똑띠체크 원본 상표와 똑띠i 도우미

- 기준: 사용자가 제공한 M1.1.1 전체 ZIP.
- **원본 잠금 이미지**: `assets/ttoktti-i-official-locked.png`와 `assets/ttoktti-check-wordmark-locked.png`는 사용자가 첨부한 이미지 바이트를 그대로 복사했습니다. 자르기, 글자 수정, 재생성, 합성을 하지 않았습니다. 화면의 CSS 크기·배치만 조절합니다.
- 메인화면에서 ‘성능점검 및 보고서 작성’ 바로가기 카드를 제거하고 ‘점검표 작성 시작하기’ 버튼만 유지했습니다. 접속 후 1초 뒤 원본 똑띠i 이미지와 손가락 안내가 버튼 주변에 나타납니다.
- 점검표 화면(`checklist.html`) 오른쪽 아래에 고정형 똑띠i 도움말을 추가했습니다. PC/모바일 지원, 추천 질문 선택 및 직접 질문 입력을 지원합니다.
- **도움말 구현 범위:** 현재는 점검표의 실존 기능에 근거한 14개 로컬 FAQ 검색입니다. 외부 AI API, LLM 학습, 자유대화 생성형 AI 호출은 연결하지 않았습니다. 모르는 질문에는 모른다고 안내합니다. 서비스용 생성형 AI 답변을 위해서는 키 보호가 가능한 서버, 자료 검색, 권한·개인정보 정책이 별도로 필요합니다.
- 도움말 위젯은 점검/DB 자료를 읽거나 쓰지 않습니다. `assets/legacy-checklist-engine.js`, `assets/cloud-sync.js`, `supabase_test_sync_setup.sql` 및 핵심 데이터 처리 소스는 원본과 동일하게 유지했습니다.
- ‘모든 페이지’는 **이 ZIP 내 메인화면 외의 실제 페이지인 `checklist.html`**에 해당합니다. 외부 사내 업무포털의 다른 페이지는 이번 ZIP에 없어 변경하지 않았습니다.
- 적용: 전체 `performance` 폴더의 경로를 유지해 배포. 운영 Supabase에 SQL 실행 금지. 배포 후 실제 로그인, 저장, PDF/Excel, 모바일 고정 위치를 검증하세요.
- 상표명 ‘똑띠체크’와 도우미명 ‘똑띠i’는 서로 다른 식별자로 사용합니다.
# M1.1.1 — A안 단순화 메인화면

- 기준 ZIP: M1.1.0 전체 버전.
- 메인화면을 A안 방향으로 더 단순하게 정리해, **"똑띠체크" 상표명과 AI 도우미 "똑띠i"가 한눈에 들어오도록** 재구성했습니다.
- 사용자가 불필요하다고 요청한 아래 텍스트/구역을 삭제했습니다.
  - `BRAND`, `MAIN WORK`, `SAFE UPDATE`
  - `TRADEMARK`, `PREMIUM HOME`
  - `01 / FIELD`, `02 / DATA`, `03 / SHARE`
- `metric-grid`, `premium-band`, `feature-grid`를 제거하고, 메인 비주얼과 단일 바로가기 카드 중심 구조로 단순화했습니다.
- 메인 비주얼은 **배경에 크게 보이는 "똑띠체크" 타이포**와 **전면의 똑띠i 캐릭터** 구성을 강화했습니다.
- 점검표 시작 동선은 유지하기 위해 하단에 `성능점검 및 보고서 작성` 단일 바로가기 카드만 남겼습니다.
- 변경 파일: `index.html`, `assets/home.css`, `manifest.json`, `README.md`
- **점검표 엔진, checklist.html, Supabase 연결·SQL, 운영 데이터, 권한, 기존 점검 내역은 변경하지 않았습니다.**
- 홈의 `점검표 작성 시작하기` 및 단일 바로가기 카드는 종전대로 `./checklist.html`을 엽니다.
