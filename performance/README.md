# M1.1.2 — 똑띠체크 원본 상표와 똑띠i 도우미

- 기준: 사용자가 제공한 M1.1.1 전체 ZIP.
- **원본 잠금 이미지**: `assets/ttoktti-i-official-locked.png`와 `assets/ttoktti-check-wordmark-locked.png`는 사용자가 첨부한 이미지 바이트를 그대로 복사했습니다. 자르기, 글자 수정, 재생성, 합성을 하지 않았습니다. 화면의 CSS 크기·배치만 조절합니다.
- 메인화면에서 ‘성능점검 및 보고서 작성’ 바로가기 카드를 제거하고 ‘점검표 작성 시작하기’ 버튼만 유지했습니다. 접속 후 1초 뒤 원본 똑띠i 이미지와 손가락 안내가 버튼 주변에 나타납니다.
- 점검표 화면(`checklist.html`) 오른쪽 아래에 고정형 똑띠i 도움말을 추가했습니다. PC/모바일 지원, 추천 질문 선택 및 직접 질문 입력을 지원합니다.
- **도움말 구현 범위:** 현재는 점검표의 실존 기능에 근거한 14개 로컬 FAQ 검색입니다. 외부 AI API, LLM 학습, 자유대화 생성형 AI 호출은 연결하지 않았습니다. 모르는 질문에는 모른다고 안내합니다. 서비스용 생성형 AI 답변을 위해서는 키 보호가 가능한 서버, 자료 검색, 권한·개인정보 정책이 별도로 필요합니다.
- 도움말 위젯은 점검/DB 자료를 읽거나 쓰지 않습니다. `assets/legacy-checklist-engine.js`, `assets/cloud-sync.js`, `supabase_test_sync_setup.sql` 및 핵심 데이터 처리 소스는 원본과 동일하게 유지했습니다.
- ‘모든 페이지’는 **이 ZIP 내 메인화면 외의 실제 페이지인 `checklist.html`**에 해당합니다. 외부 사내 업무포털의 다른 페이지는 이번 ZIP에 없어 변경하지 않았습니다.
- 적용: 전체 `performance` 폴더의 경로를 유지해 배포. 운영 Supabase에 SQL 실행 금지. 배포 후 실제 로그인, 저장, PDF/Excel, 모바일 고정 위치를 검증하세요.
- 상표명 ‘똑띠체크’와 도우미명 ‘똑띠i’는 서로 다른 식별자로 사용합니다.
