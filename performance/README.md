# M1.1.0 — 브랜드 배경형 메인화면 재구성

- 기준 ZIP: M1.0.9 전체 버전.
- 사용자가 지적한 **눈과 입이 겹쳐 보이는 문제**를 해결하기 위해, 캐릭터 얼굴 위에 얹었던 추가 표정 오버레이를 제거했습니다.
- 메인 화면에서 아래 요소를 삭제했습니다.
  - `01 눈 깜빡임` ~ `04 점검표 스캔 라인` 설명 박스
  - `움직임 끄기` 버튼
  - `상표명 똑띠체크 / AI 기반 기계설비 성능점검 어플` 배지
- 원하는 콘셉트에 맞춰 **"똑띠체크" 상표명을 배경으로 크게 배치하고, 그 앞에 똑띠i 캐릭터가 정면에서 보이도록** 메인 비주얼을 재구성했습니다.
- 메인 캐릭터에는 얼굴 오버레이 없이, 배경 후광·오비트·헬멧 체크 펄스·점검표 스캔 라인·부드러운 움직임만 유지했습니다.
- 메인화면의 브랜딩과 레이아웃을 더 단순하고 고급스럽게 정리했습니다.
- 변경 파일: `index.html`, `assets/home.css`, `manifest.json`, `README.md`
- **점검표 엔진, checklist.html, Supabase 연결·SQL, 운영 데이터, 권한, 기존 점검 내역은 변경하지 않았습니다.**
- 홈의 `점검표 작성 시작하기` 및 `성능점검 및 보고서 작성` 카드는 종전대로 `./checklist.html`을 엽니다.
- 배포: `performance/` 폴더를 기존 경로에 업로드, SQL은 다시 실행하지 않습니다.
