# M1.0.9 — 똑띠체크 상표명 반영 + 프리미엄 메인화면 + 애니메이션 4종

- 기준 ZIP: M1.0.8 전체 버전.
- 성능점검 어플의 상표명을 **똑띠체크**로 메인화면에 전면 반영했습니다.
- 메인화면의 브랜딩, 카드 배치, 조명 효과, 글래스 패널, 정보 카드 구성을 더 고급스럽게 개편했습니다.
- 캐릭터 영역에 아래 4가지 애니메이션을 모두 반영했습니다.
  1. **눈 깜빡임**: 캐릭터 얼굴 영역에 부드러운 깜빡임 효과 추가
  2. **인사 웨이브**: 캐릭터 hover 시 반갑게 인사하는 동작 강조
  3. **헬멧 체크 펄스**: 안전모 체크 심볼에 펄스 효과 추가
  4. **점검표 스캔 라인**: 클립보드 영역에 점검 스캔 라인 효과 추가
- 기존 움직임 토글 버튼은 유지했습니다. OS의 '동작 줄이기' 설정도 존중합니다.
- 새 모션은 `index.html`, `assets/home.css`, `assets/home-motion.js`, `manifest.json`, `README.md`에만 반영했습니다.
- **점검표 엔진, checklist.html, Supabase 연결·SQL, 운영 데이터, 권한, 기존 점검 내역은 변경하지 않았습니다.**
- 홈의 작업 시작 버튼 및 `성능점검 및 보고서 작성` 카드는 종전대로 `./checklist.html`을 엽니다.
- 배포: `performance/` 폴더를 기존 경로에 업로드, SQL은 다시 실행하지 않습니다. 캐시 방지를 위해 M1.0.9 쿼리를 사용합니다.

# M1.0.8 — 똑띠i 캐릭터 메인화면 애니메이션

- 기준 ZIP: M1.0.7 전체 버전.
- 메인화면 공식 캐릭터에 천천히 떠오르는 움직임, 마우스를 올렸을 때 인사하듯 기울이는 반응을 추가했습니다.
- 민트 빛 반짝임, 배경 후광, 정보칩 움직임을 추가했습니다.
- `움직임 끄기/켜기` 버튼을 추가했습니다. 브라우저 OS의 '동작 줄이기' 설정을 존중합니다.
- 모션은 CSS와 메인화면만 사용하는 `assets/home-motion.js`로 구현하였으며, 별도 라이브러리나 외부 요청이 없습니다.
- 새 JS는 로그인, 데이터베이스, 저장소, 네트워크를 읽거나 수정하지 않습니다. 토글 상태는 브라우저를 새로 열면 기본값으로 되돌아갑니다.
- **점검표 엔진, 점검표 페이지, Supabase 연결·SQL, 테스트/운영 데이터, 권한, 기존 점검 내역을 변경하지 않았습니다.**
- 홈의 작업 시작 버튼 및 `성능점검 및 보고서 작성` 카드는 종전대로 `./checklist.html`을 엽니다.
- 배포: `performance/` 폴더를 기존 경로에 업로드, SQL은 다시 실행하지 않습니다. 캐시된 CSS 파일을 방지하기 위해 M1.0.8 쿼리를 사용합니다.
- 캐릭터 전체 PNG가 미세하게 기울어지는 모션이며, 얼굴·손을 분리해 리깅한 관절 애니메이션은 아닙니다.
