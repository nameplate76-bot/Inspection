# M1.1.1 — A안 단순화 메인화면

- 기준 ZIP: M1.1.0 전체 버전.
- 메인화면을 A안 방향으로 더 단순하게 정리해, **"똑띠체크" 상표명과 AI 도우미 "똑띠i"가 한눈에 들어오도록** 재구성했습니다.
- 사용자가 불필요하다고 요청한 아래 텍스트/구역을 삭제했습니다.
  - `BRAND`, `MAIN WORK`, `SAFE UPDATE`
  - `TRADEMARK`, `PREMIUM HOME`
  - `01 / FIELD`, `02 / DATA`, `03 / SHARE`
- `metric-grid`, `premium-band`, `feature-grid`를 제거하고, 메인 비주얼과 단일 바로가기 카드 중심 구조로 단순화했습니다.
- 메인 비주얼은 **배경에 크게 보이는 "똑띠체크" 타이포**와 **전면의 똑띠i 캐릭터** 구성을 강화했습니다.
- 점검표 시작 동선은 유지하기 위해 하단에 `성능점검 및 보고서 작성` 단일 바로가기 카드만 남겼습니다.
- 변경 파일: `index.html`, `assets/home.css`, `manifest.json`, `README.md`
- **점검표 엔진, checklist.html, Supabase 연결·SQL, 운영 데이터, 권한, 기존 점검 내역은 변경하지 않았습니다.**
- 홈의 `점검표 작성 시작하기` 및 단일 바로가기 카드는 종전대로 `./checklist.html`을 엽니다.
